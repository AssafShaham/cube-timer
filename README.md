# cube-timer

## Current Features

- Inspection timer with +2, DNF handling
- Tracking of best single, mo3, ao5, ao12, ao100, ao1000, and session average
- UI providing stats of recent and best solves

## Planned Features

- Scramble generation
- Enable viewing of the scramble
- Ability to modify solves (change to +2 or DNF) and delete them
- Add configurations and customizability
